### Instalação
Para realizarmos a instalação iremos utlizar **node js**.
Mas aconselho que tenha python instalado, pois posteriormente, teremos modulos/scripts feitos em python também!

Use `nvm install latest` para instalar o node mais atualizado, em caso de duvidas de plataformas visite o site oficial: 

[Node Install](https://nodejs.org/en/download/current)

### Rodar
Para inicializar é simples, basta primeiro instalar as dependencias, com `npm install` e após finalizar rode o modulo com `node main.js`

### Comandos

Além da tabe de comandos de modulos existe uma padrão para que ele funcione como um modulo mesmo!

| Comando | Função |
|---------|--------|
| `Q, Quit` | Sair do modulo de forma segura! |
| `cls, CTRL + L` | Limpa a tela do modulo para melhor visualização |
| `?, help` | Abre a tela de comandos internos do modulo para ajuda rápida |
